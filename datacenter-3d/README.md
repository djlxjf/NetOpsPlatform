# 三维机房布局规划工具（Data Center Planner 3D）

一个**零后端、纯前端**的 3D 机房/设备间布局规划工具。基于 Three.js（WebGL）实现，
按「**平面绘制 → 门窗布置 → 3D 预览 → 设备摆放**」四阶段工作流组织，
全程实时同步：改尺寸、拖门窗、摆设备，3D 场景即时更新。

---

## 一、工作流（四阶段）

### ① 平面绘制
- 自动切换**俯视机位**，房间以带发光描边的矩形呈现。
- **直接拖动房间边缘**即可调整长（X）/宽（Z），或通过工具条数值精确输入长/宽/高（范围 6~90m，步进 0.5m）。
- 地面、网格、顶部管线、四面墙体**随尺寸实时重建**；已摆设备自动钳回房间内。
- **首次建机房为空机房**：只有平面 + 墙体，不带任何设备；顶部管线数量与位置随房间尺寸自适应，始终分布在房间内部。

### ② 门窗布置
- 自动打开立面编辑面板（后/左/前/右墙标签页）。
- 一键添加门/窗（自动寻找合法空位）；立面图中**拖动移动**、**拖拽黄色手柄调整宽/高**，属性区可精确输入宽/高/横向位置/底部高度（台面高矮）。
- **直接点击 3D 中的墙面**即可切换编辑对象。
- 合法性校验：门窗必须完整位于墙面内、门必须落地、窗台 ≥0.3m、宽高 ≥0.3m、门窗不重叠；非法时状态栏红字提示并禁止保存，3D 保持最近合法预览。

### ③ 3D 预览
- 一键回到全景机位，自由旋转/缩放/平移查看整体效果；墙体门窗洞口（`Shape + holes → ExtrudeGeometry`）与设备全部实时呈现。

### ④ 设备摆放
- 工具栏添加服务器机柜/空调机组/配电柜/UPS/灭火器（自动寻找无重叠空位）。
- **批量摆放**：「摆一列机柜 / 摆两列机柜」后点击地面空位，即沿通道成列放置（两列相对而立、含 1.3m 冷热通道，自动避开已有设备与越界位置）。
- **拖动设备调整位置**（自动钳位在房间内、旋转感知占位）、方向键微调（0.5m）、`R` 旋转 90°、`Del` 删除；悬停浮层 + 点击弹出信息面板。
- **机柜 3D 详情界面**：点击任意机柜直接进入单机柜详情（即完整 19" 42U 模型：柜内 20 台设备含端口阵列/挂耳/状态灯），支持正面/背面/内部/俯视机位切换、**点击前后门开合**、轨道旋转缩放，「← 返回机房」回到规划视图。
- 支持按编号搜索定位（相机飞向设备）、温度/密度/状态/类型四种着色（精细模型设备通过顶部状态色条呈现）。

## 二、技术方案

### 1. 场景组织
- 动态场景组 `room`：地面/网格/柱/管线/墙体全部由 `{ width, depth, height }` + 墙面布局数据驱动，提供 `rebuild(layout, dims)` 整体重建（含几何体释放）。
- 设备按类型分组，**每类一个 `InstancedMesh`**（实体 + wireframe 发光边框），`instanceColor` 逐实例着色实现热力切换；精细模型（机柜 / 灭火器）走克隆 Group，整体 draw call 维持在个位数级别。
- 相机导演：预设机位随房间尺寸自适应（全景/俯视），`easeInOut` 平滑过渡；`OrbitControls` 阻尼旋转/缩放/平移。

### 2. 交互实现
- **平面拖拽**：射线与地面平面（y=0）求交，靠近房间边缘 0.8m 内判定为拖拽边，拖动实时改 `roomDims` 并重建。
- **设备拖拽**：pointerdown 命中设备 → 记录抓取偏移 → 移动中射线投到地面 → `moveTo`（含旋转感知半占距钳位）；拖拽期间暂停轨道控制器，松手恢复。
- **点击 vs 拖动**：位移 <5px 判定为点击（选中/墙面点选），否则为拖动。

### 3. 性能策略
- 实例化渲染 + 几何复用 + 仅 3 灯无阴影；`UnrealBloomPass` 泛光可开关。
- FPS 每 500ms 统计并显示；持续 <40 帧自动降级（关泛光、像素比降为 1）。

### 4. 持久化
- localStorage（`dc3d.plan.v3`）：`{ v:3, dims, walls, racks, locked }` 持久化，阶段切换与「保存」按钮自动写入，刷新自动恢复；`locked` 记录布局锁定状态。
- 导出/导入 JSON（兼容 v2 纯墙面格式），支持迁移备份；「重置」恢复默认。

## 三、项目结构

```
datacenter-3d/
├── index.html            # 入口（import map / 阶段导航 / 面板结构）
├── package.json          # 依赖与脚本（Vite 方案）
├── src/
│   ├── main.js           # 阶段流程编排 + 统一指针交互
│   ├── config.js         # 可变房间尺寸 + 设备规格 + 热力色阶
│   ├── scene.js          # 渲染器/相机/控制器/泛光/帧率自适应/平面射线
│   ├── room.js           # 机房重建（地面/网格/柱/管线/带洞墙体）
│   ├── wallLayout.js     # 墙面数据 + 校验 + 尺寸同步 + 持久化 v3
│   ├── wallEditor.js     # 门窗立面编辑器（SVG 拖拽）
│   ├── racks.js          # 设备自由摆放 + 实例化渲染 + 着色
│   ├── cameraPresets.js  # 机位预设与平滑过渡
│   ├── ui.js             # 信息面板/状态/提示
│   └── style.css         # 深色科技风样式
└── README.md
```

## 四、依赖说明

| 依赖 | 版本 | 用途 |
|------|------|------|
| `three` | ^0.160.0 | WebGL 3D 引擎（核心、控制器、后处理） |
| `vite` | ^5.0.0 | 开发服务器与构建（可选） |

> 默认 `index.html` 通过 import map 从 CDN 加载 three（首次需联网）；离线请用 Vite 方案。

## 五、启动方式

```bash
# 方式 A：零安装（需联网）
python -m http.server 8080     # 或 npx serve .
# 浏览器访问 http://localhost:8080

# 方式 B：Vite（离线推荐）
npm install && npm run dev     # http://localhost:5173
```

## 六、操作速查
- **阶段切换**：顶部 ①②③④ 按钮；每次切换自动保存
- **①平面**：拖房间边缘 / 输入长宽高
- **②门窗**：立面编辑器拖拽 + 数值；点 3D 墙面切换墙
- **③预览**：全景/俯视机位，自由轨道
- **④设备**：工具栏添加，拖动移动，R 旋转，Del 删除，方向键微调
- **全局**：搜索定位、热力着色、泛光开关、FPS 实时显示
